# 日次集計と更新状況

期間ランキングはJSTの午前0時に更新を開始し、8人ずつ処理します。`periodRefresh` の進捗保存と各バッチの集計更新は同じトランザクションです。途中で失敗するとそのバッチはロールバックし、5分ごとの確認処理が保存済みの地点から再開します。完了した日は再計算しません。日付が変われば、その日の期間に合わせて先頭から更新します。新しい配信者の追加・通常の配信観測は従来どおり、その場でランキングを更新します。

管理画面の「更新状況」を開くと、日次集計の件数・完了時刻・10分以上の進捗停止を確認できます。ランク更新は登録アカウントを次回試行の早い順に表示し、連続失敗数・失敗理由・最終確認・最終試行・次回試行・24時間以上の更新停止を確認できます。取得不可の場合はHTTP応答を受け取った時刻も最終確認に含みます。この情報は管理者だけが参照でき、メール等への外部通知は行いません。

Steamのプレイヤーネームは管理画面を開いている間、アカウントごとに10分保持します。追加表示・検索変更では未取得または期限切れのIDだけを取得し、同時リクエストもまとめます。失敗後は1分、結果がない場合は2分待って再試行し、取得済みの名前は残します。画面から離れるとキャッシュは破棄されます。
